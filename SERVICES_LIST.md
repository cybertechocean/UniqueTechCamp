# 📋 SERVICES_LIST — UniqueTechCamp

> **Complete list of all service categories and their individual services.**  
> Use this document to create and populate services in the admin dashboard.  
> Each category becomes a `ServiceCategory` object; each bullet item becomes a `Service` object.

---

## How to Use This List

1. Go to **Django Admin → Service Categories** and create each category (use the exact name, assign a slug, emoji icon, and order number).
2. Go to **Django Admin → Services** and create one service per item, linking it to the correct category.
3. For each service, fill in: `title`, `slug`, `icon_name` (Google Material Symbol), `short_description`, `overview`, `benefits`, and `process`.
